## How to Run in VS Code
1. Open this folder in **VS Code** (or create a file named `index.html` and paste the code).
2. Make sure your computer is connected to the internet (so the CDN links for Three.js, Tailwind CSS, and Google Fonts load).
3. **Option A (Recommended):** Install the **Live Server** extension in VS Code, right-click `index.html`, and click **"Open with Live Server"**.
4. **Option B:** Simply double-click `index.html` to open it directly in Chrome, Edge, or Brave.

## How to Host for Free (for LinkedIn / Portfolio)
- **Vercel / Netlify Drop:** Drag and drop this folder (with `index.html` inside) onto Vercel or `app.netlify.com/drop` to get an instant live URL.
- **GitHub Pages:** Push `index.html` to a GitHub repository -> Settings -> Pages -> Deploy from `main` branch.
